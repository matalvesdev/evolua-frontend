## Limitação Central (registrada honestamente)

**GEOS v0.15.0 NÃO automatiza consultas externas** (web search ou APIs de LLMs
ChatGPT/Claude/Gemini/Perplexity). Confirmado empiricamente:

```bash
geos research run "CRM para fonoaudiólogas" --sources-limit 5
# → status=COMPLETED | mock=True | empty=False
```

O flag `mock=True` indica síntese determinística sobre a **base local**, não pesquisa real na web.
**Conclusão**: o baseline de citação externa da Evolua permanece o manual de 2026-08-12
(**0/5 queries, score GEO 2.4/10**). Este documento NÃO inventa respostas de LLMs.

### O que o GEOS entrega de real nesta sessão
1. **Cobertura interna das 5 target_queries**: busca FTS retorna conteúdo relevante para todas.
2. **Sinal de gap externo**: o research local associa cada query a `produto`/conteúdo interno, mas
   nenhuma evidência de presença externa — consistente com baseline 0/5.
3. **Oportunidades + experimento**: estrutura executável para a estratégia GEO já existe no GEOS.
