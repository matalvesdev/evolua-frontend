# Runbooks necessários

Priorizar: indisponibilidade de banco/login/API/IA, falha de webhook de pagamento/email, restore de backup e credencial comprometida. Cada runbook precisa gatilho, owner, passos de contenção/recuperação, validação, comunicação e pós-incidente. Não há runbook detalhado para sistema sem evidência operacional.
