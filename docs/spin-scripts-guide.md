# Spin / Scripts de Marketing

## Script de Atendimento (Spin)

Roteiro para vídeo curto (Reels/TikTok) — "Spin" é o gancho que prende a atenção nos primeiros 3 segundos.

### Fórmula do Spin

1. **Gancho (0-3s)**: Pergunta ou afirmação polêmica
2. **Problema (3-15s)**: Dor específica da fonoaudióloga
3. **Solução (15-45s)**: Mostrar o Evolua resolvendo
4. **CTA (45-60s)**: Teste grátis 14 dias

### Templates por Tema

**Gestão Clínica**
```
Gancho: "Você ainda usa papel para prontuário?"
Problema: "Perde horas organizando fichas..."
Solução: "Com o Evolua, você preenche pelo celular enquanto atende."
CTA: "Teste grátis em evolua.com.br"
```

**WhatsApp Automático**
```
Gancho: "Já perdeu paciente porque esqueceu de confirmar?"
Problema: "Lembretes manuais consomem seu dia..."
Solução: "O Evolua envia WhatsApp automático 24h antes."
CTA: "Link na bio para teste grátis."
```

**IA para Relatórios**
```
Gancho: "Quanto tempo você gasta em relatórios?"
Problema: "Horas escrevendo evolução..."
Solução: "A IA do Evolua gera o relatório em 5 segundos."
CTA: "Teste grátis em evolua.com.br"
```
