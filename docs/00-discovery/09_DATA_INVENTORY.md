# Inventário de dados

| Categoria | Exemplos observados | Sensibilidade |
| --- | --- | --- |
| Conta/organização | `Clinic`, `User`, preferências | Confidential |
| Paciente | `Patient`, contato, histórico | Highly Sensitive |
| Clínico | `MedicalRecord`, relatórios, planos, escalas, metas | Highly Sensitive |
| Áudio/IA | `AudioSession`, transcrição, contexto RAG | Highly Sensitive |
| Operação | tarefas, agenda, mensagens/WhatsApp | Sensitive/Highly Sensitive conforme conteúdo |
| Financeiro | transações, assinaturas, invoices | Confidential |
| Marketing | lead, newsletter, blog | Confidential |
| Telemetria/auditoria | eventos e logs | Internal/Confidential; nunca incluir conteúdo clínico bruto |
