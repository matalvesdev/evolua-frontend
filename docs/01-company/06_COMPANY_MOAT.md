# Moat e Estratégia de Plataforma

## Moat potencial — Proposed

| Fonte | Como se constrói | Limite ético |
| --- | --- | --- |
| Profundidade de domínio | modelo e UX do fluxo de fonoaudiologia | não inventar conduta clínica |
| Workflow integrado | menos abas e contexto perdido | não aprisionar dados |
| Confiança | segurança, privacidade, suporte e previsibilidade | não prometer certificação inexistente |
| Distribuição | conteúdo, educação, parceiros e advocacy | aprovação/consentimento para prova social |
| IA contextual | rascunhos com contexto mínimo autorizado | dados clínicos não são matéria-prima livre |

## Plataforma

**PROPOSED:** permanecer produto focado até evidência de demanda por integrações/API. Evolução possível: produto → integrações → API com escopos/auditoria → ecossistema. Marketplace, SSO e multi-unidade não são compromissos atuais.
