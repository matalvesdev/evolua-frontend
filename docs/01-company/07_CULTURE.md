# Cultura, Ética e Documentação

## Comportamentos

- Investigamos antes de assumir: reproduzir problema, ler código, ouvir cliente.
- Protegemos confiança: acesso mínimo, comunicação transparente, sem logs clínicos desnecessários.
- Simplificamos: menos dependências, telas e exceções.
- Temos ownership: quem propõe uma mudança explicita risco, medida e rollback.

## Ética de produto

Sem dark patterns, venda de dados sensíveis, cancelamento manipulativo, claims clínicos não sustentados ou IA apresentada como autoridade profissional. Dados são confiados à Evolua para uma finalidade, não apropriados para uso arbitrário.

## Documentação viva

Escrevemos decisões, comportamento, riscos e aprendizados — não transcrições de conversas. Cada documento tem owner, estado, revisão e links para fonte de verdade.
