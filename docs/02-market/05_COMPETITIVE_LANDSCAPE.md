# Cenário competitivo, TAM e wedge

Há alternativas de prontuário, software de clínica, agenda, ferramentas genéricas, planilhas, papel e WhatsApp. Perfis internos de iClinic, Ninsaúde, Simples Dental e Holmed são benchmarks, não prova atual de preços/funcionalidades; consultar e atualizar antes de uso externo.

**TAM/SAM/SOM:** calcular somente após obter dados verificáveis: profissionais/organizações endereçáveis × receita anual por cliente. Não há números nesta documentação.

**Wedge recomendado, Proposed:** organização do fluxo recorrente de atendimento com documentação assistida. Expansão segue: wedge → profundidade do workflow → adjacências úteis → equipe/clínica → integrações, nunca “resolver tudo”.
