# Onboarding, Mobile e Dashboard

O dashboard e onboarding existem no frontend. A auditoria registrada em `AGENTS.md` confirma estados de loading/error em áreas principais, mas não substitui pesquisa de usabilidade. O dashboard deve responder “o que preciso saber ou fazer agora?”, com agenda próxima, ações pendentes e trabalho inacabado — não virar coleção de gráficos.

O produto é web responsivo; PWA, offline-first e app nativo são **PROPOSED/UNKNOWN**. Antes de qualquer investimento, medir dispositivo, conectividade e conflitos de dados. Offline para dados clínicos exige modelo de segurança e sincronização explícito.
