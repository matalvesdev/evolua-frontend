## Convenções

- `VERIFIED`: confirmado em código, migrations, configuração ou testes.
- `INFERRED`: conclusão razoável, ainda não validada diretamente.
- `PROPOSED`: direção recomendada; não descreve o produto atual.
- `UNKNOWN`: depende de evidência ou decisão do founder.

Os documentos têm owner por função e devem ser revisados quando uma decisão, comportamento ou integração mudar. Veja [Source of Truth](SOURCE_OF_TRUTH.md).
