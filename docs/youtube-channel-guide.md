# Guia do Canal YouTube (@useevolua)

## Estratégia

Canal de tutoriais rápidos (3-8 min) para fonoaudiólogas que usam o Evolua.

## Formatos

### Tutorial (3-5 min) — 2x/mês
- "Como criar um prontuário no Evolua em 2 minutos"
- "Como configurar o WhatsApp automático no seu consultório"
- "Como usar a IA para gerar relatórios"

### Case (5-8 min) — 1x/mês
- Entrevista com fonoaudióloga usuária
- Mostrar antes/depois da gestão clínica

### Product Update (2-3 min) — quando lançar feature
- "Novidade: agora você pode..."
- Rápido, direto, sem enrolação

## Produção

| Item | Especificação |
|------|--------------|
| Resolução | 1920x1080 (16:9) |
| Thumbnail | Texto grande + rosto expressivo |
| Intro | 3 segundos (logo + "Evolua") |
| Microfone | Headset ou lapela (áudio limpo) |
| Edição | CapCut (gratuito) |
