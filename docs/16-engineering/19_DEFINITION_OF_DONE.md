# Definition of Done

- [ ] requisito, non-goal e casos de erro claros
- [ ] autorização, tenant, privacidade e dados sensíveis revisados
- [ ] testes proporcionais ao risco; build/typecheck/lint aplicáveis verdes
- [ ] UI responsiva, acessível, loading/error/empty adequados
- [ ] logs/audit/analytics mínimos sem dados sensíveis indevidos
- [ ] migration, rollout, rollback e suporte considerados
- [ ] docs/spec/ADR atualizados quando comportamento ou arquitetura mudam
