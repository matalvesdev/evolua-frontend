# Índice — Time Produto

## Quando acionar cada agente

| Situação | Agente |
|----------|--------|
| Discovery, priorização de backlog, user stories, roadmap, go-to-market de feature, métricas de produto | `agente-po.md` |
| Wireframes, protótipos, testes de usabilidade, design system, microcopy, handoff, acessibilidade | `agente-ux.md` |

---

## Fluxo de desenvolvimento de feature

```
Ideia / feedback de CX / dado de uso
        │
        ▼
Discovery (PO + UX)
├── Entrevistas de usuário
├── Análise de dados de uso
└── Benchmarking
        │
        ▼
Shaping (PO + Tech Lead)
├── Pitch estruturado
├── RICE score
└── Betting table (founders)
        │
        ▼
UX (UX Designer)
├── Wireframes
├── Teste de usabilidade (≥ 3 usuários)
└── UI + handoff para Dev
        │
        ▼
Build (Dev — ciclo de 6 semanas Shape Up)
        │
        ▼
Go-to-market (PO coordena com Marketing + CS)
        │
        ▼
Métricas (PO acompanha por 30 dias)
```

## Métricas de produto — metas

| Métrica | Meta |
|---------|------|
| Tempo até primeiro prontuário | < 24h |
| Retenção D30 | ≥ 65% |
| DAU/MAU | ≥ 40% |
| SUS (System Usability Scale) | ≥ 75 (Good) |
| NPS de produto | ≥ 50 |
| Task success rate (fluxos críticos) | ≥ 90% |
