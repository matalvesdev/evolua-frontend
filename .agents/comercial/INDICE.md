## Fluxo comercial

```
Lead (trial cadastrado)
  │
  ├── D+0  → CS: boas-vindas (WhatsApp + email)
  ├── D+1  → CS: ativação do 1° prontuário
  ├── D+3  → CS: ativação dos lembretes WhatsApp
  ├── D+5  → Vendas: follow-up se não ativou nenhum marco
  ├── D+7  → CS: check-in de saúde
  ├── D+10 → CS: primeiro relatório/laudo
  ├── D+12 → Vendas: resgate de trial vencendo
  └── D+14 → Decisão: converte ou churn
           │
           ├── Converteu → CS: jornada 30/60/90 dias
           │                   └── D+30: NPS
           │                   └── D+60: oportunidade de upsell
           │                   └── D+90: programa de indicação
           └── Não converteu → Vendas: sequência de reativação (30/60 dias)
```

## Métricas-chave

| Métrica | Meta | Frequência |
|---------|------|-----------|
| Trial → Pago | ≥ 30% | Semanal |
| Churn mensal | ≤ 3% | Mensal |
| NPS | ≥ 50 | Mensal |
| Tempo até 1° marco | ≤ 3 dias | Semanal |
| LTV médio | ≥ 18 meses | Trimestral |
