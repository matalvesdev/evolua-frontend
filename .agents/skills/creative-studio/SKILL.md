# Creative Studio — Evolua

## Core Responsibilities
Transform content into compelling visual assets. Own the brand's visual identity. Ensure every pixel that leaves Evolua is on-brand, beautiful, and effective.

## Brand Identity Principles
- **Clean & professional**: White space, clear hierarchy, purposeful color
- **Warm & human**: Rounded elements, friendly typography, authentic imagery
- **Clinical authority**: Precise iconography, evidence-based visuals, structured layouts
- **Accessible**: High contrast, readable fonts, ALT text on all images

## Visual Asset Catalog

### 1. Infographics
- **Purpose**: Complex information in scannable visual format
- **Format**: 1080x1920px (vertical, story-optimized), 1920x1080px (horizontal)
- **Style**: Data visualized with custom icons, clear hierarchy, Evolua palette
- **Rules**: Max 7 data points, source citations, one key takeaway
- **Output**: PNG + source file for future edits
- **Volume**: 3 per ebook, 1 per major blog post

### 2. Carousels
- **Purpose**: Educational deep-dives for Instagram, LinkedIn
- **Format**: 1080x1350px (Instagram), 1200x2400px (LinkedIn document)
- **Structure**:
  - Slide 1: Hook (bold claim or question)
  - Slides 2-6: Key points (one idea per slide)
  - Slide 7-8: Practical tips or examples
  - Last slide: CTA + branding
- **Rules**: Max 50 words per slide, 30pt+ font, high contrast text/background
- **Volume**: 10 per ebook, 3 per major blog post

### 3. Social Media Posts
- **Purpose**: Feed content for Instagram, LinkedIn, Facebook
- **Formats**:
  - Instagram Feed: 1080x1080px (square)
  - LinkedIn Feed: 1200x627px (link preview), 1200x2400px (document)
  - Facebook Feed: 1200x630px
- **Style**: Clean backgrounds, bold text overlays, Evolua logo watermark
- **Volume**: 20 social posts per ebook

### 4. Ad Creatives
- **Purpose**: Conversion-focused visuals for paid campaigns
- **Formats**:
  - Meta Feed: 1080x1080px
  - Meta Stories: 1080x1920px
  - Google Display: 300x250px, 728x90px, 336x280px (multi-size pack)
  - LinkedIn Sponsored: 1200x627px
- **Rules**: CTA must be visible above fold, 80/20 image/text ratio (Meta)
- **Volume**: 5 per campaign

### 5. Video / Motion
- **Purpose**: Reels, TikTok, YouTube Shorts, Stories
- **Format**: 1080x1920px, 9:16 vertical
- **Length**: 15-60 seconds (Reels), 60-120 seconds (educational)
- **Style**: Fast-paced, captions always on screen, hook in first 3 seconds
- **Volume**: 5 reels per ebook

### 6. Brand Assets
- Logos (horizontal, vertical, icon, monochrome)
- Color palette with hex codes
- Typography (headings, body, display)
- Iconography system (line style, consistent stroke weight)
- Photography style guide
- Presentation templates
- Email templates

## Campaign Visual Workflow

1. **Brief Review**: Understand the content, goal, channel, audience
2. **Concept Exploration**: 3 visual directions (safe, bold, unexpected)
3. **Creative Direction**: Present top concept with mood board
4. **Production**: Create all assets per asset catalog
5. **Brand Review**: Brand Guardian checks each asset
6. **Revision**: Up to 2 rounds per asset
7. **Delivery**: Export in all required formats + source files

## Design System Enforcement

### Color Palette (Reference)
- Primary: Evolua brand colors
- Secondary: Supporting palette for CTAs, highlights
- Neutral: Grays for text, backgrounds, borders
- Semantic: Success, warning, error, info

### Typography
- Headings: Bold, generous tracking, sentence case
- Body: Regular weight, 1.5 line height, 16px minimum for web
- Mobile: Minimum 14px body, 20px headings
- Accessibility: Minimum 4.5:1 contrast ratio for all text

### Imagery
- Authentic photography (not stock-looking)
- Diverse representation of therapists, patients, clinics
- Warm, natural lighting
- Brazilian context (not generic "global healthcare")

## Tools & Stack
- Design: Figma (primary), Canva (quick social assets)
- Motion: After Effects, CapCut (reels)
- AI Image: Midjourney / DALL-E (concept generation only, not final assets)
- Asset Management: Brand folder in cloud storage

## Key Metrics
- Brand consistency score (audit checklist)
- Social engagement rate on visual content
- Ad CTR by creative version
- Content production velocity (assets/week)
- Design revision cycle time
