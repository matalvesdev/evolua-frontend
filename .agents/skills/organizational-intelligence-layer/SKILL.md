# Organizational Intelligence Layer

Load this skill when: the task involves organizational memory, decision records, metrics dashboards, executive reporting, or cross-team coordination.

## Organizational Memory Standards

- **Persistência compartilhada**: todos os agentes compartilham memória
- **Nunca começar do zero**: sempre recuperar contexto relevante antes de agir
- **Obrigatório registrar**: decisões anteriores, arquitetura, branding, prioridades estratégicas, métricas, feedbacks, incidentes, aprendizados
- **Compartilhamento**: todo conhecimento relevante propagado para outros agentes
- **Toda decisão importante**: registrada com racional explícito

## Operational Intelligence Standards

Monitorar continuamente: throughput, cycle time, bottlenecks, eficiência dos agentes.
Produzir reports automáticos semanais/mensais no formato executivo (destaques, métricas, riscos, recomendações).

## Cross-Team Coordination Standards

**Sempre**: compartilhar contexto, explicar tradeoffs, documentar reasoning, levantar riscos cedo, consultar especialistas quando necessário, evitar retrabalho, evitar silos, colaborar continuamente.

## Agentes

### Organizational Memory Agent
- **Responsabilidade**: memória persistente compartilhada entre todos os agentes
- **SOP**: registrar decisões importantes, arquitetura, branding, prioridades, métricas, feedbacks, incidentes, aprendizados. Garantir que nenhum agente comece do zero.
- **Trigger**: decision record, context retrieval, knowledge handoff, incident learning

### Decision Intelligence Agent
- **Responsabilidade**: rastreamento e qualidade das decisões organizacionais
- **SOP**: catalogar decisões com racional explícito, revisar outcomes, identificar padrões de acerto/erro
- **Trigger**: decision log, outcome review, decision pattern analysis

### Operational Intelligence Agent
- **Responsabilidade**: inteligência operacional — eficiência dos processos e fluxos
- **SOP**: monitorar throughput, cycle time, bottleneck detection, eficiência dos agentes
- **Trigger**: operational KPI, efficiency report, process bottleneck

### Metrics Intelligence Agent
- **Responsabilidade**: inteligência de métricas — definir, coletar, analisar, agir
- **SOP**: manter catálogo de métricas, correlacionar dados, detectar anomalias, produzir insights
- **Trigger**: metric definition, anomaly detection, KPI review, metric correlation

### Executive Reporting Agent
- **Responsabilidade**: reports executivos automáticos para CEO, CTO, CPO, CMO, CFO
- **SOP**: consolidar dados de todos os layers, produzir reports semanais/mensais com formato executivo (destaques, métricas, riscos, recomendações)
- **Trigger**: weekly report, monthly report, board deck, investor update

### Cross-Team Coordination Agent
- **Responsabilidade**: coordenação entre layers e agentes
- **SOP**: identificar dependências entre times, facilitar comunicação, evitar retrabalho, documentar interfaces
- **Trigger**: cross-layer dependency, coordination gap, handoff, alignment meeting
