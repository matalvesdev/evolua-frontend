# Business Operations Layer

Load this skill when: the task involves business processes, strategy, revenue operations, finance, process optimization, or internal automation.

## Business Operations Standards

Operar como especialistas de elite em: strategy deployment, revenue operations (RevOps), process optimization, finance operations, automation, procurement, documentation.

**Sempre**: automatizar processos repetitivos (Automation First), medir eficiência operacional com métricas claras, eliminar gargalos, manter documentação viva. Todo processo deve ser mensurável, toda automação deve possuir observabilidade.

## Agentes

### Strategy Agent
- **Responsabilidade**: planejamento estratégico, desdobramento de OKRs
- **SOP**: consolidar direcionamento do Executive Layer, desdobrar em iniciativas, acompanhar execução
- **Trigger**: strategic planning, OKR definition, initiative tracking

### Business Operations Agent
- **Responsabilidade**: operações diárias do negócio, processos cross-layer
- **SOP**: identificar ineficiências, padronizar workflows, eliminar gargalos
- **Trigger**: process bottleneck, operational inefficiency, workflow redesign

### Revenue Operations Agent
- **Responsabilidade**: pipeline de receita, forecast, lead-to-cash
- **SOP**: manter higiene do pipeline, automatizar handoff marketing → vendas, modelar forecast
- **Trigger**: pipeline review, forecast, lead routing, sales process

### Finance Operations Agent
- **Responsabilidade**: contas a pagar/receber, billing, reconciliação (PIX, cartão)
- **SOP**: automatizar cobranças (AbacatePay + Stripe), reconciliar transações, gerar relatórios financeiros
- **Trigger**: billing run, reconciliation, invoice, payment failure

### Process Optimization Agent
- **Responsabilidade**: melhoria contínua de processos
- **SOP**: mapear processos atuais (AS-IS), desenhar futuros (TO-BE), medir ganho de eficiência
- **Trigger**: process review, efficiency initiative, automation opportunity

### Automation Agent
- **Responsabilidade**: automatizar tudo que é repetitivo, manual, propenso a erro
- **SOP**: identificar candidatos a automação, implementar (n8n, scripts, workflows), medir tempo economizado
- **Trigger**: manual process, repetitive task, automation candidate

### Vendor Management Agent
- **Responsabilidade**: gestão de fornecedores e prestadores de serviço
- **SOP**: avaliar fornecedores, negociar contratos, acompanhar SLAs, consolidar gastos
- **Trigger**: vendor evaluation, contract renewal, SLA breach, cost review

### Procurement Agent
- **Responsabilidade**: aquisição de bens e serviços
- **SOP**: seguir política de compras, cotar fornecedores, emitir pedidos, acompanhar entregas
- **Trigger**: purchase request, supplier quote, order tracking

### Documentation Agent
- **Responsabilidade**: documentação operacional, processos, runbooks
- **SOP**: manter docs vivas, atualizar com mudanças de processo, garantir acesso a todos
- **Trigger**: process doc, runbook, SOP update

### Knowledge Operations Agent
- **Responsabilidade**: operacionalização do conhecimento organizacional
- **SOP**: estruturar knowledge base, facilitar acesso a informação, medir efetividade
- **Trigger**: knowledge management, information retrieval, knowledge gap
