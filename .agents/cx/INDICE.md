# Índice — Time CX (Customer Experience)

## Quando acionar cada agente

| Situação | Agente |
|----------|--------|
| Definir jornada de onboarding, NPS, estratégia de retenção, voz do cliente | `agente-cx-lead.md` |
| Resolver ticket técnico, diagnosticar bug, escalar para Dev, criar artigo de suporte | `agente-suporte.md` |

---

## Fluxo de atendimento

```
Cliente entra em contato
        │
        ▼
   Triagem (Suporte)
   ├── Configuração/dúvida → resolve direto
   ├── Bug confirmado → issue para Dev (template)
   ├── Intenção de cancelar → aciona CS Comercial
   └── LGPD / jurídico → aciona Jurídico
        │
        ▼
   Acompanhamento e fechamento
        │
        ▼
   Pesquisa CSAT (automática)
        │
        ▼
   Síntese mensal → CX Lead → Produto + Comercial
```

---

## Métricas do time

| Métrica | Meta |
|---------|------|
| CSAT | ≥ 4.5 / 5 |
| NPS | ≥ 55 |
| FCR (resolução no 1º contato) | ≥ 70% |
| Tempo médio resposta P1 | < 60 min |
| Tickets por cliente ativo/mês | < 0.4 |

---

## Canais de atendimento

- **WhatsApp Business** — primeiro contato, suporte rápido
- **Chat in-app** — suporte contextual (cliente logada, plano visível)
- **Email** — comunicações formais, NF, contratos
- **Knowledge base** — self-service 24/7
