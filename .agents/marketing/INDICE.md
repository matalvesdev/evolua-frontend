## Como usar cada agente

### Para operação de conteúdo em tempo real
Abra `agente-operacoes-conteudo.md`, forneça: EVENTO + CONTEXTO + CANAL.

### Para direcionamento estratégico
Abra `agente-cmo.md` (João Branco), forneça: CONTEXTO + DECISÃO + RESTRIÇÕES.

### Para gerar uma legenda nova
Abra `agente-legenda.md`, forneça: PILAR + TEMA + FORMATO + CTA.

### Para roteirizar um Reels
Abra `agente-roteiro-reels.md`, forneça: TIPO + DURAÇÃO + TEMA + TOM.

### Para estruturar um carrossel
Abra `agente-carrossel.md`, forneça: PILAR + TEMA + NÚMERO DE SLIDES + CTA FINAL.

### Para montar o mês
Abra `agente-calendario.md`, forneça: MÊS/ANO + META + RESTRIÇÕES.

### Para crescimento e aquisição
Abra `agente-growth.md`, forneça: FASE + PROBLEMA DE FUNIL + DADOS + RESTRIÇÕES.

### Para email e jornada de leads
Abra `agente-crm.md`, forneça: SEGMENTO + OBJETIVO + DADOS + CANAL.

### Para campanhas pagas
Abra `agente-paid-media.md`, forneça: OBJETIVO + BUDGET + AUDIÊNCIA + CRIATIVOS.

### Para SEO e blog
Abra `agente-seo.md`, forneça: TEMA/KW + PERSONA + OBJETIVO + EXTENSÃO.

### Para parcerias e comunidade
Abra `agente-comunidade.md`, forneça: OBJETIVO + CONTEXTO + ALVO.
