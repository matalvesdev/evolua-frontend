# Índice — Contabilidade & Financeiro

## Agentes

| Arquivo | Agente | Quando usar |
|---------|--------|-------------|
| `agente-contador.md` | Contador / Controller | NF-e, impostos, DAS, folha, obrigações acessórias, LGPD financeiro |
| `agente-cfo.md` | CFO Fracionado | Modelagem financeira, pricing, runway, data room, decisões estratégicas |

## Quando acionar cada agente

```
Pergunta fiscal ou contábil?
  → agente-contador.md

Decisão financeira estratégica?
  → agente-cfo.md

Exemplos:
  "Quando emitir NF para clínica com CNPJ?" → Contador
  "Devo ajustar os preços dos planos?" → CFO
  "Quanto de DAS pago esse mês?" → Contador
  "Quanto runway tenho se contratar mais 1 dev?" → CFO
  "Preciso reter IR da fatura desse cliente?" → Contador
  "Quais métricas mostrar para o investidor?" → CFO
```
