# Política de Segurança

Para relatar uma vulnerabilidade, use o canal privado definido pelos maintainers do repositório. Se este canal ainda não estiver publicado, abra contato privado com o owner do projeto; **não** publique detalhes exploráveis, dados de pacientes, tokens ou segredos em issues.

Inclua impacto, reprodução mínima, ambiente e evidência sem dados sensíveis. A equipe deve confirmar recebimento, avaliar severidade, conter o risco e comunicar atualização factual. Não há programa público de bug bounty ou SLA declarado neste arquivo.
